# CONTRIBUTING.md

Short version: this portfolio is not accepting outside contributions.

It is published so you can read and study it. It is not a community project.

## Bugs

If you think you found a bug, open an issue with:

- what you did (clicked / typed / resized),
- what you expected,
- what happened instead — a screenshot if the page mis-rendered,
- your browser, OS and whether you have reduced motion or autoplay enabled.

Fixes are considered only when the diagnosis is convincing; they are never owed a merge.

## Pull requests

PRs from strangers are unlikely to be accepted:

- the engine, the choreography and the layout are mine;
- typo/content fixes aimed at the public files are welcome as issues instead — they take
  30 seconds to apply myself;
- anything that re-licenses, removes or rewords the license or attribution is rejected
  without review.

## Contact

Report a bug: GitHub → issues (link in the README footer).
Do not email. There is no contact inbox.

## What you may absolutely not change in a fork

(If you were granted permission to work on this) the license, the copyright notice, the
attribution in `NOTICE.md` and the `AUTHOR`/`OWNER` values in the repo's metadata.
